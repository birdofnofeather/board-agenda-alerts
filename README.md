# Board agenda alerts

Each week a new set of meeting agenda are uploaded to this site: 

https://ceo.lacounty.gov/agendas/



Each agenda has a Board Motion Item(s) section on the first few pages (generally this first page). If there is nothing listed or says "None" move onto the next agenda document. If this section does have an item, extract it. That will become a card in our database. For any agenda that does include an item in that section, it typically also has backup materials farther in the document. Read that section(s) and only that section(s) for each corresponding item and generate a very brief summary. When you click on the card in our web-based database, the card expands to include that summary. It also should include a link to the agenda document, anchored to the specific corresponding section in the backup materials; the date and time of the meeting (this you can find on the first page of the agenda) hyperlinked with the Teams meeting link (that's also to be found on the first page of the corresponding agenda); and the name of the committee.

Check the site weekly for a new slate of agendas and repeat the process. There should be two tabs on our site: next meeting and past meetings.
